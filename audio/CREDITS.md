# Demo music credits

Short (~24s) loops used in the interactive Attune demo on `/attune`. All three are used under
**Creative Commons Attribution 4.0 (CC BY 4.0)** — free for commercial use *with credit*. These are
loudness-normalized excerpts of longer tracks; the source files are not redistributed here.

**Visible attribution:** a "Demo music" credit line renders in the `/attune` demo UI (crediting Scott
Buckley and Josh Woodward). That line is the CC-BY attribution — if you swap a track, update **both** this
file and that credit.

**License rule for this use (keep it clean):** CC0 or CC BY only. No `-NC` (Attune is commercial), no `-ND`
(the demo applies real-time EQ = a derivative), no `-SA` (share-alike is a headache for a paid app). See the
site plan (`docs/plan.md`) for the same rule applied to the measurement data.
